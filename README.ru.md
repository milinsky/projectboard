# Projectboard

[English](README.md) | **Русский** | [简体中文](README.zh-CN.md)

Десктоп-дашборд локальных проектов (macOS, Python 3.14 + PySide6): сканирует каталог
с проектами (по умолчанию ~/Projects), находит папки с собственным README.md
(«верхний README побеждает»), показывает мастер-детейл: таблица с поиском слева,
отрендеренный README справа, кнопка «Открыть в ZCode».

## Возможности

- Сканирует настраиваемый корень проектов (по умолчанию `~/Projects`, максимальная глубина 8)
- Проект — папка с собственным `README.md` («верхний README побеждает»)
- Мастер-детейл: таблица с поиском + отрендеренный README справа
- Кнопка «Открыть в ZCode» для выбранного проекта
- Индексация по кнопке с JSON-кэшем индекса — без сканирования при старте
- Интерфейс на русском, английском и упрощённом китайском
- Устанавливается как macOS-приложение: **Projectboard.app**

## Требования

- macOS, Python 3.14 (`python3.14`)

## Установка

```bash
python3.14 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

Два способа.

Разработка — из корня проекта:

```bash
.venv/bin/python main.py
```

Повседневный — приложение Projectboard.app из /Applications (двойной клик).
При первом запуске может понадобиться правый клик → «Открыть»
(см. [Первый запуск неподписанного приложения](#первый-запуск-неподписанного-приложения)).

## Сборка и установка приложения (Projectboard.app)

Скрипт собирает Projectboard.app и устанавливает его в /Applications. Запускается
из корня проекта, без аргументов. Предусловие: приложение закрыто. Повторный запуск
полностью пересобирает и обновляет установленное приложение.

```bash
./scripts/build_app.sh
```

## Первый запуск неподписанного приложения

Бандл не подписывается (подпись и нотаризация в проект не входят). Локально собранный
бандл обычно не получает карантин-атрибут и запускается обычным двойным кликом.
Если Projectboard.app не запускается двойным кликом (например, репозиторий был скачан
или перенесён и macOS пометила бандл карантином) — первый запуск: правый клик по
Projectboard.app → «Открыть».

## Обновление приложения

После обновления кода пересоберите и переустановите приложение:

```bash
git pull
./scripts/build_app.sh
```

Если папка проекта была перемещена или переименована, лаунчер (абсолютные пути)
перестанет находить файлы проекта, и приложение не запустится. Лечение: откройте
терминал в папке проекта и выполните `scripts/build_app.sh` — бандл пересоберётся
с актуальными путями.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests/ -q
```

## Настройка

Корень сканирования меняется в окне приложения (поле корня + «Обзор…»);
индексация — только по кнопке «Индексировать». Данные приложения: `data/`
(`config.json` — настройки, `index.json` — кэш индекса).

## Язык интерфейса

Меню «Язык» (Системный / Русский / English / 简体中文) задаёт язык интерфейса;
применяется после перезапуска приложения.

## Переводы (разработка)

Исходники строк — русские литералы `tr()`. `scripts/update_translations.sh`
регенерирует `translations/*.ts` / `*.qm` (pyside6-lupdate / lrelease) и завершается
ошибкой, если есть незаполненные переводы. Первичную генерацию `.ts` выполняйте
прямым `lupdate`.
